## Second pass — Dhruba's 2.05 report, then a whole-text Sanskrit audit (2026-11-12)

Owner authorization: Dhruba reported that 2.05 prints **भैक्षमपीह / bhaikṣamapīha** where his text reads **भैक्ष्यमपीह / bhaikṣyamapīha**, and asked that all 700 verses be checked for the same class of fault ("i hope we don't have many errors"). His quoted "भुज्जीय" was checked and needs no change: the edition already prints भुञ्जीय / bhuñjīya. The 2.05 reading is a genuine defect; the rest of this pass records what a whole-text re-reading found.

**Method.** GRETIL (same pinned mirror, re-cloned) was parsed to all 700 verses and compared verse by verse with the canonical `d`/`t` after folding nasal/visarga/avagraha/punctuation variants and removing GRETIL's chapter headers; GRETIL's own 2.20/2.22 label swap and chapter-13 offset were compensated in code. Every mismatch of two or more letters (there are only three texts in the whole edition) was then adjudicated against a second witness: **Gita Supersite** (`https://heritage.iitk.ac.in/SBG/<chapter>.<verse>`, the IIT Kanpur Supersamūla mūla + padaccheda) plus the four derivative corpora already on hand. Single-letter differences were reviewed as a class, not individually: they are dominated by known GRETIL defects (`.h`/`.d` transposition, `jotir`/`nirjotir`, `sahastra-`, `icchhāmi`, dropped avagraha and visarga, `sat`/`san` OCR) and by this edition's documented conventions.

**Verdicts.** Fifteen corrections, all in `source/ch*.json` (`d`, `t`, matching pāda, matching word row, and the literal/paraphrase strings that quoted the old reading). Where a printed word changed, its gloss was changed only as far as the new word required.

| Verse | Correction | Evidence |
|---|---|---|
| 2.05 | भैक्षम् → **भैक्ष्यम्** / bhaikṣam → bhaikṣyam | GRETIL `bhaikṣyam apīha`; Gita Supersite; all four corpora. The reported defect. |
| 1.05 | काशीराजः → **काशिराजः** / kāśīrājaḥ → kāśirājaḥ | Gita Supersite mūla and padaccheda (`काशि-राजः`); GRETIL; all four corpora. The edition alone wrote the long ī. |
| 8.01 | कि कर्म → **किं कर्म** / ki karma → kiṃ karma | Gita Supersite; GRETIL; all four corpora. In the verse line only: the pāda's own leading word stays `कि` / `ki`, because sandhi does not run from a word boundary (the edition's convention, e.g. 2.02 `कुतस्त्वा`). |
| 11.16 | त्वा → **त्वां** / tvā → tvāṃ | Gita Supersite mūla and padaccheda (`त्वाम्`); GRETIL; all four corpora. The word row already read त्वाम् / tvām, so the verse line and pāda were brought into line with it. |
| 11.21 | अमी हि त्वा → **अमी हि त्वां** / tvā → tvāṃ | Same three witnesses. The second त्वां in this verse was already correct. |
| 11.32 | ऋतेऽपि त्वा → **ऋतेऽपि त्वां** | Same three witnesses; the boundary review had already written त्वाम् in this verse's word row. |
| 11.20 | रूपमिदं तवोग्रं → **रूपमुग्रं तवेदं** / rūpamidaṃ tavograṃ → rūpamugraṃ tavedaṃ | Gita Supersite mūla and padaccheda (`रूपम् उग्रम् तव इदम्`); GRETIL; all four corpora. Word order and the four word rows were reordered to match. |
| 13.20 | कार्यकरण° → **कार्यकारणकर्तृत्वे** / kāryakaraṇa° → kāryakāraṇa° | Gita Supersite mūla and padaccheda (`कार्य-कारण-कर्तृत्वे`); GRETIL; all four corpora. The compound means effect-and-cause, so the gloss ("effect and cause"), not instrument, was corrected with it. |
| 16.04 | अतिमानश्च → **अभिमानश्च** / atimānaśca → abhimānaśca | Gita Supersite mūla and padaccheda (`दर्पः \| अभिमानः`) and Gambhirananda, which both read अभिमान. **GRETIL and all four derivative corpora read अतिमानश्च**, so this is the one reading among the fifteen where the witnesses genuinely split; it was applied on the Supersite and the commentary, and Dhruba confirmed अभिमानश्च against his own printed copy on 2026-11-12. |
| 16.13 | लब्धमिदं → **लब्धमिमं** / labdham idaṃ → labdham imaṃ | Gita Supersite; GRETIL `labdham imaṃ prāpsye`; all four corpora. Object of prāpsye, so accusative; the first pāda's `इदम्` (idam adya … labdham) is unaffected. |
| 18.28 | नैकृतिकः → **नैष्कृतिकः** / naikṛtikaḥ → naiṣkṛtikaḥ | Gita Supersite; GRETIL `naiṣkṛtikolasaḥ` (avagraha dropped, rest exact); all four corpora. |
| 18.35 | धृतिः सा तामसी **मता** → धृतिः सा **पार्थ** तामसी | Gita Supersite; GRETIL; all four corpora. Gambhirananda's note: “Some editions read pārtha in place of matā”. This edition was following the minority. |
| 18.59 | यद्यहंकारम् → **यदहंकारम्** / yadyahaṃkāram → yadahaṃkāram | Gita Supersite; GRETIL `yad ahaṃkāram`; three of four corpora (one prints यदहंकारम् with aṅ). Sandhi of yad before a vowel. |
| 18.72 | प्रणष्टः → **प्रनष्टः** / praṇaṣṭaḥ → pranaṣṭaḥ | Gita Supersite; GRETIL; all four corpora. |
| 18.75 | श्रुतवानिमं गुह्यतमं परम् → **श्रुतवानेतद्गुह्यमहं परम्** / śrutavān imaṃ guhyatamaṃ param → śrutavān etad guhyam ahaṃ param | Gita Supersite mūla and padaccheda (`श्रुतवान् \| एतत् \| गुह्यम् \| अहम् \| परम्`); GRETIL; all four corpora. The second pāda and its four word rows were rebuilt; the literal was rewritten because the old one rendered a different sentence. |

**Retained, with the alternative recorded.** 18.68 keeps **इमं** (imaṃ) against the one corpus that prints इदं: GRETIL, the Supersite and the other three corpora agree with this edition. 3.08 keeps **प्रसिद्ध्येद**, the reading of the Supersite and most printed editions, against GRETIL's single-द `prasidhyed` (which follows one Shankara-bhāṣya witness). 5.23, 9.25, 8.24, 12.12, 17.06 and 10.05 were each checked against the Supersite and are correct here; GRETIL alone misprints `prak śarīra`, `pitṛn`, `jotir`, `abhyāsāj jñānād` for this edition's visarga forms, `karṣayantaḥ` (this edition already prints कर्शयन्तः after an earlier review) and `tuṣṭis tapo` for its visarga.

**Why the Sanskrit could drift.** Nothing in the build compares the text with an outside edition: `check_padas.py` proves the 2,800 pādas rebuild from their own word rows, and the fixtures pin *this* edition's decisions, so a reading wrong in both scripts and in its word row is internally consistent and passes everything. The fifteen faults here are of that kind — single-syllable or single-letter slips (क्ष/क्ष्य, करण/कारण, त/भ, मता/पार्थ, ण/न) of the sort produced by typing or dictating Devanagari from memory rather than copying a witness, and this edition's mixed orthography (anuṣvāra against class nasals, optional avagraha, छ/श) points to assembly from several sources over time. Each correction above was checked against two independent witnesses before editing, and the GRETIL parser plus the Supersite comparison are now reproducible, so the same audit can be re-run.

**Verification.** `python3 build.py` passes: 94 Python tests, 939 document assertions, site health, SEO, 9,658 study checks, 50 title advisories / 0 blocking; all 2,800 pādas reconstruct with zero spelling or diacritic flags. 16.13 is now a word-count change (+1 pāda row, **9,507 = 9,389 pāda rows + 118 speaker rows**), so that baseline was refreshed in `run_gita_app.js`, `source/method.html` and `README.md`; 16.13 was also added to the reviewed same-gloss pairs in `tests/test_semantic_audit.py` (इदम् and इमम् are one lemma). The generated `docs/title-review.md` worksheet was regenerated with `audit_titles.py --markdown`, never hand-edited. Browser checks skipped (no Playwright here).

| Verse | Change | Why |
|---|---|---|
